# Importación

El usuario selecciona tipo, fuente y archivo. La página resuelve el esquema compatible, muestra columnas esperadas y envía su `template_id` internamente; no presenta selector de Plantilla.

Muestra estado, totales y errores del lote. Admite fuentes bancarias, Mercado Pago, Tienda Nube, ARCA y CSV previamente generado por OCR para facturas físicas.
