# Importación

- **Propósito:** seleccionar fuente, ID inequívoco de plantilla y tipo, y enviar un CSV.
- **Entrada/salida:** selección y archivo → lote aceptado o error accionable.
- **RF:** RF-02, RF-04.
- **Dependencias:** operaciones API de catálogo y lotes.
- **Exclusiones:** mapeos personalizados, carpetas y cargas en segundo plano.
