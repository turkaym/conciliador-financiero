# Propuestas

La página contiene:

- **Automáticas:** sincroniza al entrar, permite Buscar coincidencias y muestra ambos registros lado a lado.
- **Manual:** filtros independientes y selección 1:1.
- **Auditoría:** filtros persistentes, exportación CSV y reversión.

Después de confirmar se vuelve a consultar el listado completo para retirar alternativas caducadas. Un 409 por propuesta obsoleta se transforma en mensaje informativo y refresco.
